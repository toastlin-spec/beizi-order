# 杯子洪了 團購點餐系統

「杯子洪了手搖專賣店」的團購線上點餐網頁。大家用手機點餐，訂單集中存到 Google 試算表，團主可在後台統計、修改並匯出 CSV 訂購單。

## 功能

**前台點餐**
- 填寫姓名、電話（必填）
- 依菜單（2026.08 版）分類瀏覽或搜尋 68 款飲品
- 冰熱、甜度、加料（可複選）、杯數、自備環保杯（每杯折 $5）
- 依菜單規則自動限制選項：甜度固定、不可做熱飲、白泡泡最低微冰、冰沙冰量固定、二選一口味
- 購物車：一人可加入多種飲品後一次送出
- 店家優惠「來店買五送一」：整筆訂單每滿 6 杯送 1 杯（送最低價），即時顯示折抵後金額

**團主專區**（右上角，需輸入密碼）
- 訂購人數、總杯數、原價合計、優惠後應付店家
- 品項統計（依飲品與規格分組，方便打電話給店家）
- 訂單明細：可修改、刪除
- 匯出 CSV（Excel 開啟不亂碼）、複製表格、清空訂單（清空前自動封存）

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 點餐網頁（前台＋團主專區），單一檔案，無外部相依 |
| `apps-script.gs` | Google Apps Script 後端，負責把訂單存進 Google 試算表 |

## 部署（Google Apps Script）

1. 新建一個 Google 試算表 →「擴充功能」→「Apps Script」
2. 把預設的 `.gs` 檔內容換成 `apps-script.gs`（檔名不用改）
3. 檔案旁的「＋」→「HTML」→ 命名為 `Index`，貼上 `index.html` 全部內容
4. 「部署」→「新增部署作業」→ 類型「網頁應用程式」
   - 執行身分：我
   - 誰可以存取：所有人
5. 完成授權後，「網頁應用程式網址」（結尾 `/exec`）就是點餐網頁，分享給大家即可

之後修改程式碼：「部署」→「管理部署作業」→ ✏️ → 版本選「新版本」→「部署」，網址不變。

直接用瀏覽器打開 `index.html` 則為**本機測試模式**，訂單只存在該裝置的瀏覽器。

## 設定

`index.html` 最上方的設定區：

| 設定 | 說明 |
|---|---|
| `ADMIN_PIN` | 團主密碼，需與 `apps-script.gs` 的 `ADMIN_KEY` 相同 |
| `PROMO_MODE` | `'store'` 來店買五送一／`'delivery'` 外送買十送一／`'none'` 不使用 |
| `API_URL` | 網頁放在 Apps Script 以外的網站時，填入 Apps Script 網址 |

> ⚠️ 團主密碼寫在網頁原始碼中，只能防止誤操作，不是真正的安全保護。若儲存庫為公開，請在部署前更換密碼，且不要把真正使用的密碼提交上來。
